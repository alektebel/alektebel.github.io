jev-trader

jev-trader es un bot personal de trading en modo simulado (paper) que construyo para aprender a medir de forma honesta si una estrategia funciona. Corre en mi propio ordenador como servicio, no es un servicio público ni una app instalable: solo yo lo uso, con mi propia cuenta de Gmail y mi propio token de Telegram.

Qué hace:

  • Lee mis correos de la newsletter Milk Road (acceso de solo lectura a Gmail) y usa un modelo de lenguaje para extraer las vistas de mercado que contienen.
  • Con esas vistas y datos de precios, un analista LLM redacta tesis por valor; el bot decide operaciones sobre la API paper de Alpaca.
  • Envía avisos a mi chat privado de Telegram (órdenes, errores, resúmenes) y guarda todo el historial en una base de datos SQLite local.

El único dato que sale de mi máquina hacia los proveedores de OAuth es el contenido de los correos que el bot analiza (procesado por la API del modelo de lenguaje) y las órdenes paper a Alpaca. No hay base de datos compartida, ni analítica, ni terceros.
